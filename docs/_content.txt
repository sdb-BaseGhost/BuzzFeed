# BuzzFeed 社交媒体平台 — 技术文档

## 一、项目概述

BuzzFeed 是一个类 Twitter/微博 的社交媒体平台，支持用户注册登录、发布图文/视频内容、关注/粉丝关系管理、以及基于推拉结合模型的 Feed 流信息分发。

**技术栈总览：**

| 层级 | 技术选型 |
|------|---------|
| 后端框架 | Spring Boot 3.5.6 + Java 17 |
| 前端框架 | Vue 3 + Vite 5 + Pinia + Vue Router 4 |
| 样式方案 | Tailwind CSS 3 |
| 数据库 | MySQL（MyBatis ORM） |
| 缓存 | Redis（Lettuce 客户端） |
| 消息队列 | Apache Kafka |
| 对象存储 | MinIO |
| 认证方案 | JWT（jjwt 库）+ Spring Security |
| 视频处理 | FFmpeg（转码 + 封面截帧） |
