项目结构

Frontend 目录布局

Frontend/ 目录结构
Frontend/
├── src/
│ ├── api/ // Axios 实例 + 请求封装
│ │ ├── index.js // Axios 实例、拦截器
│ │ ├── auth.js // 登录/注册接口
│ │ ├── feed.js // Feed 流接口
│ │ ├── post.js // 发布/点赞/评论接口
│ │ ├── user.js // 用户信息/关注接口
│ │ └── search.js // 搜索接口
│ ├── assets/ // 静态资源
│ ├── components/ // 通用组件
│ │ ├── layout/ // 三栏布局骨架
│ │ ├── feed/ // Feed 相关组件
│ │ ├── post/ // 发布/帖子组件
│ │ ├── user/ // 用户卡片/头像
│ │ └── common/ // 按钮、输入框、弹窗等
│ ├── composables/ // 逻辑复用 hooks
│ ├── mock/ // Mock 数据
│ ├── router/ // 路由配置
│ ├── stores/ // Pinia 状态管理
│ ├── views/ // 页面级组件
│ ├── App.vue
│ ├── main.js
│ └── style.css // Tailwind 入口
├── public/
├── index.html
├── tailwind.config.js
├── vite.config.js
└── package.json

路由规划

页面路由
/login // 登录页
/register // 注册页
/ // 首页 Feed（需登录）
/following // 关注页 Feed
/explore // 搜索/发现页
/notifications // 通知页
/messages // 消息页
/profile/:userId // 用户资料页
/profile/:userId/followers // 粉丝列表
/profile/:userId/following // 关注列表
/post/:postId // 帖子详情（含评论）
